# FFVS 1.0.0 — Release notes

**FFVS** is a local-first CLI that turns a JavaScript/TypeScript project into a **queryable semantic graph**.

## What you can do

- Index a project into a local `.ffvs/` graph
- Ask who calls a function, who depends on a module, and what a change may impact
- Find IMPORTS paths between modules
- Run compositional queries with the **Query Language 1.0**
- Export deterministic JSON for scripts and CI

## Start in minutes

```bash
npm install && npm run build && npm link   # from this repository
cd examples/demo
ffvs init && ffvs index .
ffvs query 'search "loadUser" traverse callers resolution resolved describe'
ffvs query 'select modules where name = "repository.ts" impact describe'
```

Full walkthrough: [docs/quick-start.md](../quick-start.md).

## Query Language 1.0

Stable stages: `select` · `where` · `search` · `traverse` · `path` · `impact` · `describe`

Resolution-aware traverse and `impact along calls` are included. See [docs/language/overview.md](../language/overview.md).

## Honest limitations

- JS/TS only in 1.0
- PATH is **IMPORTS-only**
- CALLS are approximate (RESOLVED / AMBIGUOUS / UNRESOLVED)
- No JOIN/SQL, no mutation, no cloud, no AI
- Graph load dominates runtime on large projects

Details: [docs/limitations.md](../limitations.md) · [docs/ffvs-1.0-scope.md](../ffvs-1.0-scope.md)

## Why 1.0 now

Research through 0.8.x showed the core is useful enough to install and use. 1.0 freezes that core as a product — not the end of the roadmap.
