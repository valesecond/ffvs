# Language principles

1. **Evidence first** — constructions must map to observed compositions (EXP-DSL-0001).
2. **Thin surface** — language ⊆ query model; convenience verbs stay derived.
3. **Uncertainty visible** — CALLS/IMPORTS resolution statuses remain part of results.
4. **Same CORE** — DSL compiles to the same operations the CLI calls.
5. **Orthogonal ops** — SELECT, FILTER, SEARCH, TRAVERSE, DESCRIBE, PATH, RELATIONS.
6. **No stealth SQL** — do not adopt SQL aesthetics without evidence.
7. **Fail clearly** — empty sets and ambiguous entity refs are explicit.
8. **Smaller than the product** — not every CLI flag needs a keyword.
