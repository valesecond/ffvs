# Examples

Small fixtures for manual exploration live primarily under `fixtures/`.

## mini-js

```bash
cd examples/mini-js
ffvs init
ffvs index .
ffvs inspect
ffvs functions
```

## basic-project (recommended Phase 1 demo)

```bash
cd fixtures/basic-project
ffvs init
ffvs index .
ffvs inspect UserService
ffvs imports
ffvs graph UserController
```
