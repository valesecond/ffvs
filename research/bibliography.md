# Bibliography & Related Work

Lista inicial de leituras e ferramentas relacionadas. Não é exaustiva. O objetivo é mapear o estado da arte para posicionar o FFVS com honestidade.

## Ferramentas e sistemas

- CodeQL — consultas semânticas sobre bases de código.
- Semgrep — busca e regras multi-linguagem orientadas a padrões.
- Joern — Code Property Graphs e querying.
- Sourcegraph / SCIP / LSIF — navegação e indexação de símbolos.
- tree-sitter — parsing incremental multi-linguagem.
- Dependency Cruiser, madge — dependências em ecossistemas JS.
- Understand (SciTools) — análise e métricas comerciais.
- OpenTelemetry — telemetria e traces.
- Git — histórico e evolução.

## Temas bibliográficos (buscar e citar formalmente em trabalhos futuros)

- Program comprehension
- Software architecture recovery
- Static program analysis
- Code property graphs
- Impact analysis
- Software evolution / mining software repositories
- Domain-specific languages for developer tools
- Empirical studies of developer tooling

## Notas de posicionamento

O FFVS **não** afirma, neste estágio, superar CodeQL, Joern, Semgrep ou IDEs. O diferencial hipotético a investigar é a combinação **local-first + CLI/linguagem operacional + modelo unificado evolutivo** (estático → histórico → runtime), com foco em composição e extensibilidade.

Ao citar estes trabalhos em textos acadêmicos, use fontes primárias e referências completas (DOI/ISBN). Esta lista é um mapa de estudo, não um survey publicado.
